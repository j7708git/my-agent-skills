健檢專案工作流並探勘可做成 skill 的重複操作。

要健檢的專案：$ARGUMENTS

## 執行方式

1. **專案清單取自 `$ARGUMENTS`**（以逗號分隔多個專案 id）。
2. **缺省回問**：沒有參數時，先問使用者要健檢哪些專案——可列出
   `project-notes/projects/` 下的既有 id 供挑選，**不要猜測**。
3. 對**每個專案 id 平行派一個 `workflow-optimizer` subagent**（背景並行），
   並在提示中告知**專案 id** 與**今天的日期**（報告檔名用）。
4. 全部完成後**彙整摘要**給使用者：各報告路徑、高優先級項目、存疑項目。

## 提醒使用者

- 這是**手動觸發**，不做自動偵測、不排程。
- 產出是**建議**，**不會自動套用**；閉環需使用者核准後由 PM／implementer 落地，
  並在下次健檢驗證。
